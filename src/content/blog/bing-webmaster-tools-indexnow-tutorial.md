## Resposta rápida

O Bing Webmaster Tools é a ferramenta gratuita da Microsoft para monitorar e indexar sites no Bing. Como o índice do Bing alimenta o Microsoft Copilot e é uma das fontes de busca usadas por outros assistentes, cadastrar o site, enviar o sitemap e ativar o IndexNow é uma das ações de GEO com melhor custo-benefício. O cadastro pode ser feito em minutos importando o site direto do Google Search Console.

## O que é o IndexNow?

O IndexNow é um protocolo aberto que permite que os sites avisem instantaneamente aos buscadores (Bing e Yandex) sempre que uma página for criada, atualizada ou excluída. Em vez de esperar pelo rastreador (crawler), o motor de busca recebe a notificação em tempo real.

## Como configurar em minutos

1. Acesse o Bing Webmaster Tools e faça login com conta Microsoft, Google ou X.
2. Importe seu site diretamente do Google Search Console para validação instantânea.
3. Envie seu sitemap XML (`/sitemap.xml`).
4. Instale um plugin ou gere uma chave de API para ativar o protocolo IndexNow.
